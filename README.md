# Лабораторная работа №3: Параллельное умножение матриц (MPI)

## Описание работы
Целью данной лабораторной работы была модификация программы перемножения квадратных матриц для её параллельной работы с использованием технологии **MPI**.
В ходе работы проведена серия экспериментов по исследованию зависимости времени выполнения программы от размера матрицы и количества вычислительных процессов.

## Описание модулей 

- **`main.cpp`**: Основной модуль, реализует распределенные вычисления с использованием MPI. Процесс с рангом 0 считывает входные данные и рассылает их другим процессам (используя `MPI_Bcast` и `MPI_Send`). Каждый процесс вычисляет свой блок строк результирующей матрицы.
- **`generator_m.py`**: Скрипт на Python для генерации тестовых матриц случайных значений и сохранения их в файлы `matrix_a.txt` и `matrix_b.txt`.
- **`verify.py`**: Скрипт верификации результатов. 
- **`graphic.py`**: Скрипт для визуализации результатов. Строит график зависимости времени выполнения от размера матрицы для разного числа процессов.
- **`run_exp.py`**: Скрипт для автоматизации запуска серии экспериментов с различными параметрами.

## Выводы и анализ результатов

1. **Эффект параллелизации**: 
   - Использование MPI позволило существенно сократить время выполнения задачи. 
   - При увеличении числа процессов с 1 до 4 время выполнения уменьшается примерно в 3 раза, что свидетельствует об эффективном распределении нагрузки между процессами.

2. При переходе от 4 процессов к 8 процессов прирост производительности становится менее выраженным (время уменьшается не в 2 раза, а меньше). 
3. **Итог**: Программа успешно распараллелена с использованием MPI, верификация результатов проходит успешно, график подтверждает корректность проведенных измерений.
