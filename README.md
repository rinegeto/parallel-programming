## Параллельное умножение матриц на суперкомпьютере с использованием MPI  


### Цель работы

Запустить программу параллельного умножения матриц (реализованную с использованием MPI) на вычислительном кластере через систему управления заданиями SLURM. Провести экспериментальные замеры времени выполнения для различных размеров матриц (от 100×100 до 2000×2000) и разного количества вычислительных потоков (1, 2, 4, 8).

#### 5. Анализ результатов и выводы
* 1. Масштабируемость по размеру матрицы:
Время выполнения растёт кубически с увеличением размера матрицы, что соответствует теоретической сложности алгоритма умножения матриц: O(N³).
Например, при увеличении размера с 800 до 1600 (×2) время возрастает примерно в 8–9 раз (618 → 5412 сек для 1 потока).
* 2. Эффект параллелизации:
- При увеличении числа потоков с 1 до 8 достигается ускорение:
  Для 2000×2000: 10234 сек → 2103 сек (4.9× ускорение);
  Для 800×800: 618 сек → 162 сек (3.8× ускорение);
- На малых матрицах (≤400) выигрыш от параллелизации минимален, тк накладные расходы на инициализацию MPI и синхронизацию процессов сопоставимы со временем вычислений.
3. Ускорение не является линейным: переход с 4 до 8 потоков даёт меньший прирост, чем с 1 до 4.
4. Оптимальная конфигурация:
- Для матриц ≥1200×1200 наиболее эффективна конфигурация с 8 потоками.
- Для малых матриц (≤400) достаточно 2–4 потоков, тк дальнейшее увеличение не оправдано.
