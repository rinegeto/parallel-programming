# Лабораторная работа №4: Параллельное умножение матриц (CUDA)

## Описание работы
Программа умножения квадратных матриц адаптирована с использованием технологии CUDA. Проведены эксперименты по исследованию влияния размера матрицы (200-2000) и конфигурации блоков (8×8, 16×16, 32×32) на время выполнения ядра.


## Описание модулей

- **`main.cu`**: Основной модуль на CUDA. Реализует ядро умножения матриц, управление памятью GPU и замер времени через CUDA Events
- **`generator_m.py`**: Генератор тестовых матриц 
- **`verify.py`**: Скрипт верификации результатов через NumPy 
- **`graphic.py`**: Построение графика производительности

## Выводы и анализ

1. **Влияние размера блока**:
   - Увеличение размера блока с 8×8 до 16×16 даёт ускорение примерно 30% 
   - Переход к 32×32 даёт незначительный прирост (примерно 1-2%)

2. **Масштабируемость**:
   - Время выполнения растёт кубически с увеличением N
   - GPU эффективно обрабатывает большие матрицы благодаря большому количеству параллельных ядер

3. **Сравнение с CPU**:
При N=2000 CPU: 36.8 сек. При N=2000 GPU (CUDA, блок 16×16): 0.048 сек. Задача выполнилась быстрее примерно в 760 раз

4. Для задач умножения матриц оптимальным является блок 16×16
